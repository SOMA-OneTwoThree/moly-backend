# 한국어 해볼 것·조심할 것 개선 기준

사용자 요청: 한국어 행동 문구가 짧고, 문맥·분량·정성 면에서 아쉽다. 다른 운세는 유지하고 이 두 항목만 개선한다.

검수 기준 버전: `ko-actions.r2`. 앞선 검토본은 사용자의 실제 예시 검토에서 문장 연결과 표현의 불명확함이 드러났다. 기존 통과 판정으로 이번 수정본을 승인하지 않고, 아래 기준으로 312개 항목을 모두 다시 읽는다.

## 이번 재검수에서 반드시 확인할 것

1. **무엇을 하라는 말인지 바로 알 수 있어야 한다.** ‘미뤄둔 즐거운 일’처럼 성격만 꾸민 ‘일·것·방식’으로 행동을 대신하지 않는다. 특정 취미를 임의로 정하는 대신, ‘하고 싶었지만 시간이 없어 못 했던 것’처럼 실제 상황과 대상을 분명히 한다. 이 표현 자체를 모든 카드에 반복하는 것은 금한다.
2. **둘째 문장은 첫째 문장의 방법이나 이유를 설명해야 한다.** 두 문장을 따로 떼어 각각의 행동·대상·이유를 적어 본다. 둘째 문장에서 남의 반응·자기 축하·인정 욕구 등 다른 목적이 갑자기 생기면 고친다. 첫 문장에서 빠진 전제를 독자가 상상해야만 연결되는 문장도 반려한다.
3. **일상에서 실제로 쓰는 결합으로 쓴다.** ‘어렵게 마련한 여유를 남의 시선에 맞추느라 쓰기’처럼 추상적인 것을 주고받거나 소비하는 표현을 풀어 쓴다. 같은 뜻의 추상어로 바꾸거나 연결어만 덧붙이는 수정은 통과시키지 않는다.
4. **일반적인 말을 불필요하게 메시지·물건·장소에 한정하지 않는다.** 사용자 교정에 따라 완드 8 역방향의 ‘받은 메시지가’는 ‘받은 말이’로 바꾼다. 다른 항목도 전달 수단이 운세 의미에 필요하지 않으면 말·대답·대화로 읽을 수 있게 다듬는다.
5. **친절한 설명과 불필요한 설명을 구분한다.** 현재 반말과 1~2문장 분량은 유지한다. 같은 지시를 다시 하거나, 새 주장으로 글자 수만 늘린 둘째 문장은 고친다. 설명할 내용이 없으면 한 문장으로 끝내며, 한 줄짜리 행동 이름으로 되돌리지는 않는다.
6. **본문의 어색한 표현도 그대로 베끼지 않는다.** 카드·정역·본문의 뜻과 조건은 유지하되, 표현이 부자연스러우면 행동 항목 자체를 평이하게 쓴다. 작성자가 적은 연결 근거만 그럴듯한 경우는 승인하지 않는다.

각 항목은 새 문구만으로 먼저 읽는다. 검수자는 `do`와 `pause` 각각의 실제 행동과 둘째 문장의 관계(방법·이유·범위·한 문장 완결)를 짧게 자기 말로 남긴 뒤 원본문과 대조한다. 관계를 쉽게 설명할 수 없으면 문장이 먼저 고쳐져야 한다. 이 기록은 자동 템플릿으로 채우지 않는다.

## 범위

- 카드 78종 × 정역 2종의 총운별 `do`·`pause`: 156쌍, 총 312개
- 기존 총평·두 단락·카드 키워드와 판단을 읽고 한국어로 새로 집필한다
- 후속 사용자 승인에 따라 확정한 두 필드를 한국어 정본과 영어·일본어에 반영한다. 언어별 312개, 세 언어 936개가 대상이다
- 점수·추첨·멱등성·DB는 유지한다. 같은 배포에서 API 기본 응답에 `overall.flow`를 포함하고 `categories`만 잠그며, 모바일 수정은 별도 작업이다
- 작업·검수를 마친 뒤 dev PR·머지·개발 배포·실제 검증까지 수행한다. 운영 배포는 범위에 없다

## 문장의 기준

1. 행동 이름만 쓰지 않는다. 어떤 상황에서 무엇을 하면 좋을지, 왜 조심해야 하는지를 이 항목만 읽어도 알 수 있게 쓴다.
2. 친근한 반말의 완결된 1~2문장으로 쓴다. 대략 35~80자를 참고하되, 필요한 말이 끝나면 멈춘다. 모든 문구를 같은 길이·같은 틀로 맞추지 않는다.
3. `do`는 오늘 해볼 만한 행동 하나가 중심이다. 두 번째 문장이 있다면 방법·범위·맥락을 더한다. 여러 숙제를 줄줄이 덧붙이지 않는다.
4. `pause`는 피할 행동이나 주의할 이유가 명확한 안내다. UI 제목이 ‘조심할 것’이므로 부정 명령형은 그대로 자연스럽게 읽히되 ‘하지 않기’를 주의 대상으로 내놓는 이중 부정은 쓰지 않는다.
5. 두 문장은 실제로 이어져야 한다. 막연한 ‘좋은 흐름·에너지·변화·가능성·가치·자신을 믿기’로 분량을 채우지 않는다. `~겠어`, `흐름이야`, ‘이기려고 무리하기’ 등 사용자가 반려한 표현을 피한다.
6. 같은 카드의 두 항목이 단순히 ‘해라/하지 마라’로 뒤집힌 쌍이면 개선한다. 본문이 가진 서로 다른 행동·관찰을 우선 활용한다. 서로 다른 소재를 억지로 넣어 분리하지 않는다.
7. 카드·정역 해석과 본문의 운 판단·확신 정도·조건을 지킨다. 조언의 이해를 돕는 일상적인 설명은 가능하지만 본문에 없는 사건·개인 사정·성과 보장을 추가하지 않는다.
8. 좁은 물건·장소·직업·관계에 억지로 한정하거나, 뻔한 일정·체크리스트·생산성 강의로 모든 카드를 바꾸지 않는다.
9. 기존 본문을 그대로 잘라 두 칸에 붙이지 않는다. 핵심은 공유하되, 문장이 그 항목만으로 자연스럽고 완결돼야 한다.
10. 어미의 억지 다양화보다 자연스러움이 먼저다. `~해봐`, `~좋아`, `~마`는 쓸 수 있지만 두 문장마다 같은 주문을 반복하지 않는다. 불필요한 ‘오늘은/한 번/조금/한 가지’도 남발하지 않는다.

## 집필과 검수

작성자는 각 키의 총평·본문 전문·기존 두 행동·근거표를 읽고 쓴다. 새 `do`·`pause`와 기존 한국어 번들 해시, 참고한 근거 해시, 연결 근거를 함께 기록한다. 해시는 읽은 버전을 식별하며 품질을 보증하지 않는다.

별도 검수자는 전체 156쌍을 읽고 ① 단독 이해 ② 자연스러움 ③ 문장 연결 ④ 행동 구체성 ⑤ 본문·카드 일치 ⑥ 두 항목의 중복을 각각 1~5로 평가한다. 항목별 4점 이상이어야 통과하며 미달은 키와 이유를 남겨 재작성한다. root는 기준·표본·검수 지적과 수정본을 확인한다.

`ko-actions.r2`에서는 기존 해시가 같아도 새 기준으로 실제 재독해야 한다. 작성자와 독립 검수자는 기준 버전을 명시한다. 구조·점수·해시가 맞는 것만으로 한국어 품질을 통과시키지 않는다.

본문과 두 행동을 함께 표시한 전체 비교 문서와, 좋은 날·주의할 날·여러 카드 계열을 포함한 비교 예시를 만든다. 구조·중복·문장 수·길이 검사와 실제 독해 검수의 결과를 구분한다. 인간 원어민 감수라고 표현하지 않는다.

## 확인한 서비스 참고 범위

- [포춘에이드 오늘의 별자리](https://www.fortunade.com/unse/free/star/daily.php?gtype=2): 2026-09-16 열람, 제공된 2026-09-15의 12별자리 실제 본문 109~193행. 상황·제안·이유가 이어지는 방식을 참고하며 문구와 과장된 확신은 차용하지 않는다.
- [네이트 오늘의 운세](https://fortune.nate.com/contents/freeunse/todayunse.nate): 같은 날 열람, 실제 본문 9~13행. 일반적인 관계·활동에 관한 직접적인 서술만 참고한다. 성별 고정관념·사고 예언·건강 단정은 채택하지 않는다.

## 후속 반영 시 지킬 것

한국어 개선안이 확정되면 기존 정본에 두 필드만 반영하고, 영어·일본어의 행동 의미도 다시 대조한다. 언어별 검수 해시를 실제 재검수 없이 갱신하거나 기존 승인 증거로 새 문구를 통과시키지 않는다. 첫 방문 원고·근거 해시·문구 버전·manifest·전체 대조 문서를 함께 갱신해야 하며, 당일 저장 결과의 보존 규칙은 유지한다.

## 영어·일본어 행동 문구 검수

기준 버전은 `ko-actions.r2-localization`이다. 확정 한국어의 대상·조건·행동·이유를 유지하되 문장 순서를 직역하지 않는다. 일본어는 친근한 です・ます체, 영어는 일상적인 표현과 기존 영국식 철자 기준을 따른다. 두 언어 모두 1~2문장 안에서 충분히 설명하고 한국어 글자 수에 맞추지 않는다.

작성자와 다른 검수자가 각 언어 156쌍을 독립적으로 읽는다. 두 행동을 단독으로 읽고, 기존 현지어 총평·본문과 확정 한국어 행동을 대조한다. 각 행동과 문장 연결을 개별 기록하고 자연스러움·가독성·총운 적합성·의미 일치·확신 정도를 각각 4점 이상 확인한다. 수정된 항목은 다시 읽은 뒤 새 해시를 기록한다.

`source-overall.json` 및 `source-overall.en.json`, `source-overall.ja.json`은 이번 수정 전 전문을 고정한 비교 원본이다. 작성 중인 정본이 바뀌어도 기존 표현·검수 근거가 소실되지 않도록 보존한다.
