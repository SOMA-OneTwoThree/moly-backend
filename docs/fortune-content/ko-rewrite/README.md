# 한국어 운세 편집 정본

상태: **한국어 본문 780개와 총운 짧은 문구 468개 작성·전수 검수 완료. 서버 연결 전 편집 정본.** 2026-09-15 사용자가 승인한 [전차 정방향 예시](approved-example.md)와 [집필·검수 기준](CRITERIA.md)을 따른다.

이 문서의 서버 연결 전 범위는 한국어 확정 단계의 기록이다. 이후 요청한 일본어·영어와 서버 연결의 최신 상태는 [현지화 작업 기록](../localization/README.md)을 따른다. 후속 작업에서도 이 한국어 원고는 그대로 유지한다.

## 수량과 역할

| 분야 | 원고 | 담당 | 독립 검수 |
| --- | ---: | --- | --- |
| 총운 | 본문 156 + 총평·해볼 것·조심할 것 468 | 총운 담당 에이전트 | root |
| 애정 | 본문 156 | 애정 담당 에이전트 | root |
| 금전 | 본문 156 | 금전 담당 에이전트 | root |
| 학업·직장 | 본문 156 | 애정 집필을 마친 에이전트가 별도 원고로 담당 | root |
| 건강 | 본문 156 | 금전 집필을 마친 에이전트가 별도 원고로 담당 | root |

분야별 집필을 독립 작업으로 나누고 동시 실행 가능한 담당부터 진행했다. 작성자에게 수정할 키와 문제를 전달했으며 주 담당자는 대체 원고를 쓰지 않았다. 수정된 원고는 번들 전체를 다시 읽고 판정했다.

## 파일

- `*.json`: 분야별 카드 정·역방향의 완성 한국어 원고. `paragraphs`의 원소 하나가 화면에 표시할 한 단락이다.
- `*.briefs.json`: 카드·키워드·채택한 운의 판단·작성 조건·근거. 기존 원고 문장을 번역하지 않는다.
- `*.author-review.json`: 작성자 자체 검토 기록. 독립 검수와 구분한다.
- `review.json`: 주 담당자가 실제로 읽고 판정한 기록. 해시는 최종 읽은 원고를 식별할 뿐 품질 인증을 대신하지 않는다.
- `source-briefs.json`: 이전 조사에서 원고를 제외하고 추린 780개 해석 근거. 한국어 말투의 정본이 아니다.
- `generated/`: 같은 원고를 분야별·카드별로 그대로 표시한 Markdown 전문과 정적 검증 결과.

## 원고 읽기

[같은 카드 한 장의 다섯 분야 전체](generated/all-cards.md)에서 카드 정·역방향별 키워드와 작성 조건을 본 다음 문구를 읽을 수 있다. 분야별로 읽으려면 [총운](generated/overall.md), [애정](generated/love.md), [금전](generated/money.md), [학업·직장](generated/work.md), [건강](generated/energy.md)을 사용한다.

원고를 수정하는 파일은 분야별 JSON이다. 전문 Markdown을 따로 고치지 않는다. `python docs/fortune-content/ko-rewrite/build_review_artifacts.py`로 전문을 갱신하고 같은 명령에 `--check`를 붙여 누락·형식·검수 해시·전문 일치를 확인한다. 이 도구는 앱을 실행하거나 DB에 접속하지 않으며 독해 검수 기록을 대신 만들지 않는다.

## 참고 자료와 검수 범위

한국어 서비스에서 실제 읽은 본문과 이번 집필에 사용한 범위는 각 `*.author-review.json`에 기록한다. `source-briefs.json`과 여기서 이어받은 개별 출처의 열람일은 이전 의미 조사 기록이며, 이번 단계에서 모든 원문 사이트를 새로 열었다는 뜻이 아니다. 이번에 추가로 확인한 출처는 작성자 기록에 별도로 구분한다.

근거표는 카드의 전통적 의미, 이번에 채택한 해석, 분야에 적용한 상황을 구분한다. 특히 건강 본문의 일상 예방 행동은 카드 원전의 의학적 진단이나 처방으로 취급하지 않는다. 작성자 자체 검수와 root의 별도 전수 검수를 구분하며, 실제 읽은 원고의 해시를 남긴다.

## 최종 검수 결과

- 작성자 자체 재독과 root 별도 독해: 5분야 각각 156개, 총 780개. 총운의 총평·해볼 것·조심할 것 468개도 함께 읽었다. 수정본은 다시 읽었으며 미해결 지적은 0건이다.
- 카드별 조합 검수: 메이저 5장·컵 3장·완드 2장·소드 2장·펜타클 2장의 정역 28세트, 140개 본문을 다섯 분야로 묶어 비교했다. 개별 원고 전수 검수와 이 조합 표본 검수를 구분한다.
- [정적 검증 결과](generated/validation.json): 780개 키·근거·작성자 해시·root 현행 통과 기록 일치. 오류 0건, 검수 대기 0건, 경고 0건. 전문 생성 후 `--check` 통과.
- 본문 전체 중복과 총평·조심할 것의 동일 문구는 0건이다. 짧은 판단인 ‘재물운이 좋아.’ 3회와 ‘받은 도움에 고마움 전하기’ 2회는 각 카드 문맥에 맞아 유지했다. 본문 내용이 다른 짧은 표현에 억지 동의어를 만들지 않았다.

검수는 한국어 에이전트가 수행했으며 인간·원어민 감수 인증을 뜻하지 않는다. 서버·API·DB 테스트 결과는 이 검수에 포함하지 않는다.

## 이전 작업 정리

이전 미커밋 v7 카드 원고·코드·문서 23파일은 저장소 외부 `../fortune-work-archive/pre-korean-reset-20260915-175401/`에 patch와 파일 원본, 기준 커밋 manifest로 보관했다. 기존 작업 공간의 해당 변경만 보관 후 기준 dev `6ef287f5`로 되돌렸다. 다른 작업 공간과 사용자의 미추적 문서는 수정하지 않았다.

이전 원고의 에이전트 통과 기록은 사용자가 반려한 문체의 기록이며 이번 한국어 품질 판정으로 재사용하지 않는다. 이전 번역과 서버 변경은 필요할 때 따로 재검토할 수 있게 보관했고 이번 원고에 합격 상태로 섞지 않는다.

## 서버 반영과의 관계

이번 단계에서는 한국어 원고와 근거·검수만 확정한다. 서버의 영어·일본어 자산과 점수·점성술·카드 추첨·DB는 변경하지 않는다. 특히 애정의 3단락과 학업·직장의 2단락을 기존 API 구간 배열에 억지로 끼워 넣지 않는다.

후속 연결 시 필요한 일:

1. 새 한국어 의미와 판단을 기준으로 EN/JA를 새로 집필·검수한다.
2. 총운 3구간/분야 2구간과 표시용 단락을 구분하는 응답·모바일 렌더링 계약을 확인한다. 애정 3단락을 손실 없이 표시해야 한다.
3. 확정한 계약으로 카탈로그 검증, 첫 방문 정본 동기화, manifest·문구 버전·생성 문서를 함께 갱신한다.
4. 개발 환경에서 실제 카탈로그·언어 전환·첫 방문·동일 입력 재현·프로필 수정·기존 snapshot·광고 해금 보존을 검사한다.

이번 원고 작업에는 DB 마이그레이션이나 운영 데이터 변경이 없다. 커밋·push·PR·배포 및 로컬 앱·DB·Docker·pytest 실행도 하지 않는다.
