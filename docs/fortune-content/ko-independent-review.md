# 독립 점수 운세 한국어 편집 기록

2026-09-09. 대상 `app/resources/fortune/copy.v2.json`, 문구 버전 `fortune-copy.v3-independent.1`.

## 편집 범위

- 총평 10구간 × 20묶음 = 200묶음의 제목·풀이·행동·주의를 검토하고 문장부호를 적용했다.
- 연애·금전·직장·활력 각각 10구간 × 20개 = 800문단을 5문장으로 재구성했다.
- 분야 `text`는 2구간(2문장 + 3문장), 총평 `flow`는 3구간(1문장 + 2문장 + 2문장)을 유지했다. 구간 내부에 개행은 없다. 실제 한 문단 표시는 클라이언트의 합치기 방식과 함께 확인해야 한다.
- 내부 `coral` ID의 한국어 표시값은 기존 승인값인 `회색`, `#9E9E9E`를 유지한다. 색상 목록 12개를 확인했으며 별도 UI 파일은 이 작업의 수정 범위가 아니다.

## 3언어 공통 의미 구성

새로운 문장 5,000개를 모두 독립 집필했다고 주장하지 않는다. 기존 검수본의 ID별 핵심 뜻을 보존하면서 같은 분야·같은 점수대의 보조 뜻을 사용해 문단을 구성하고 표현을 교정했다. 한국어·일본어·영어 담당자가 다음 기준을 공유했다.

- 분야: 해당 ID의 판단·권유 2문장 + 같은 구간에서 6칸 뒤 ID의 판단·권유 2문장 + 12칸 뒤 ID의 권유 1문장
- 총평: 해당 ID의 풀이 3문장 + 6칸 뒤 ID의 행동 1문장 + 12칸 뒤 ID의 주의 1문장
- 20개 범위에서 순환한다. 예를 들어 `v01`은 `v07`·`v13`의 보조 뜻을 사용한다.
- 단어를 옮기는 번역 대신 조건·판단 강도·권유의 의미를 맞춘다. 다른 분야나 점수대의 뜻은 끌어오지 않는다.

전체 문단이 동일한 고정 마무리를 공유하지 않게 했으며, 원문 재사용 때문에 서로 다른 문단 안에서 같은 문장이 최대 3회 등장한다. 따라서 전문 중복 0건을 모든 문장 고유함이나 반복 체감의 완전한 해소로 해석해서는 안 된다.

## 주요 교정

- `마음의 여백`, `하루의 중심`, `풍성한 선택`, `가능성을 열어줘`, `마음에 자리를 줘` 등 추상 표현을 확인·제안·선택의 구체적인 행동으로 바꿨다.
- 불필요한 `네`·`너다운`을 덜어내되 `자신의 말로`, `직접 해본 경험`처럼 뜻을 구별해야 하는 부분은 명시했다.
- 매번 명령으로 끝나지 않게 일부 후반 권유를 설명형으로 다듬었다. 상대의 반응·돈·건강에 관한 결과 보장은 추가하지 않았다.
- 총평 `overall.d10.general/v13`의 몸 상태 예측을 일정 조정·누락 확인으로 바꿨다. 총평이 독립적인 활력 점수를 대신 판단하지 않게 하려는 변경이며 다른 언어에도 공유했다. 보조 문장으로 쓰이는 같은 구간 `v01`·`v07`에도 반영된다.
- 단순 치환 검토에서 발견한 `더 더`, `재미을`, `힘으로 해봐` 등의 문법 문제를 교정했다.

## 확인 결과와 한계

| 확인 | 결과 |
| --- | --- |
| 총평 / 분야 ID | 200 / 800 유지 |
| 풀이 문장 수 | 1,000문단 모두 5문장 |
| 전문 중복 | 0건 |
| 문장 최대 재사용 횟수 | 3회 |
| 구간 내부 줄바꿈 | 0건 |
| `~겠어`, `흐름이야` | 0건 |
| 제목·행동·주의 끝 마침표 | 전체 적용 |
| 한 문단 내 `좋아` 종결 | 3회였던 20문단을 교정해 최대 2회 |
| 실제 catalog 금칙/어색한 표현/총평 분야 침범 정규식 | 전체 한국어 문자열 검색 0건 |
| 본문 글자 수 | 공백·마침표 포함 116~175자, 중앙값 약 144자 |

구조·문장부호·금칙 표현·중복은 전체 자산에서 검사했다. 실제 `fortune_catalog.py`의 `_PLACEHOLDER_RE`, `_FORBIDDEN_RE`, `_AWKWARD_COPY_RE`, `_OVERALL_DOMAIN_RE`를 읽어 자산 전체에 적용했고, 검사에 걸린 `무난` 표현을 교정했다. 의미 검토는 50개 경로의 `v05`·`v15` 100문단, 낮음·중간·높음의 `v01`·`v10`·`v20` 표본 및 추상 표현 검색에 걸린 문장들을 읽으며 수행했다. `좋아` 종결이 세 번 나오는 20문단도 별도로 읽고 수정했다. 전량의 사람/원어민 심사를 마쳤다고 주장하지 않는다.

기획의 한국어 180~260자는 초기 편집 범위였으며 이번 본문은 그보다 짧다. 기존 짧은 문장을 다섯 문장으로 구성해 실제 분량은 늘었으나, 사용자에게 보여준 긴 예시와 같은 밀도까지 충족했다고 단정하지 않는다. 화면에서 5줄을 보장하지 않으며 작은 화면·큰 글꼴에서의 읽기와 사용자가 원하는 분량 체감은 통합 검토 항목으로 남긴다. 반복 조합이 실제 연속 사용에서 어떤 느낌인지도 별도 선택 로직 검증과 함께 확인해야 한다.

이 기록은 편집·구조 검사의 범위를 설명한다. 원어민 검수, 의학적·금융적 예측의 유효성, 자동 AI 판별을 통한 품질 보증은 하지 않는다. 코드·DB·운영 배포·PR은 이 한국어 편집 작업에서 수행하지 않았다.
