# 한국어 문구 집필·검수 기록

상태: `agent_reviewed` 원고 검수 완료, 통합용 카피 동결. 이 기록은 사람이 수행한 원어민 검수를 뜻하지 않는다.

## 범위

- 총평 80개 점수·유형 조합과 분야 40개 점수·분야 조합 각각 20개 변형: 한국어 2,400묶음, 11,200개 표현.
- 총평은 제목·풀이 3문장·행동·주의, 분야는 판단과 대응을 담은 2문장이다. 20개 공통 상황의 의미는 `briefs.json`을 따른다.
- 한국어 담당 에이전트가 start/advance/focus/coordinate/change/recover 및 love/work를 직접 집필했다. 총괄 에이전트가 organize/balance 및 money/energy를 직접 집필하고 한국어 담당이 저·중·고점 표본을 교차검수했다.
- 5개 → 10개 → 20개 상황 단계마다 행동 대상을 확인했다. 각 점수 문구를 직접 작성했으며 접두 문장이나 동의어 치환으로 변형 수를 채우는 생성기는 사용하지 않았다. `.rows`에서 JSON으로 옮기는 스크립트는 문구를 생성하지 않는 구조 포장 도구다.

## 의미 대조 기준

- 10점수 구간에서 같은 상황과 행동·주의의 원인을 유지한다. 저점은 범위 축소와 확인, 중간은 현재 조건에 맞는 진행, 고점은 같은 행동의 구체성과 깊이를 높인다.
- 높은 점수여도 외부의 성공·수익·호감·답변·평가를 보장하지 않는다. 낮은 점수는 재난이나 관계 파탄을 예고하지 않는다.
- start는 착수 조건, advance는 진행 중 다음 단계, focus는 주의와 이해, coordinate는 뜻과 조건의 조율, change는 변경의 범위와 근거, organize는 정리와 완료, recover는 생각을 놓고 판단 여유를 남기는 선택, balance는 서로 다른 필요의 배분으로 구분했다.
- recover 총평에는 신체·의학적 상태를 넣지 않는다. 활력 분야는 활동의 속도·양과 참여 여유를 다룬다.
- 애정은 현재 연인이나 특정 관계를 전제하지 않으며 자신의 표현과 상대의 응답을 구분한다. 일·학업은 회사원 또는 학생 한쪽으로 제한하지 않는다. 금전은 실제 소비 판단을 다루고 수익을 약속하지 않는다.
- 삼언어는 공통 상황을 공유한다. 각 언어 담당과 총괄의 별도 교차검수가 있으며, 한국어 담당이 영어·일본어 전체를 최종 승인했다는 의미는 아니다.

## 주요 교정

- start 초안의 일부 do/pause가 점수에 따라 다른 행동으로 바뀐 문제를 발견해 200묶음의 행동·주의와 대응 문장을 공통 의도에 다시 맞췄다. 주변 분위기에 따른 확대, 준비 전 약속, 이전 경험의 동일시 등 주의의 원인까지 보존했다.
- `무난`을 포함한 상투적 중립 표현을 제거했다. 고점의 반복적인 호평은 해당 상황에서 할 수 있는 구체적 판단으로 바꿨다.
- 총평에 들어간 `몸`, `식사`, `과제` 등 분야 경계 표현을 제거했다. 회복은 휴식 시간·알림·기억 부담·마감 재촉·비교·복귀의 작은 단계로 구체화했다.
- 동일 셀의 제목·풀이·행동·주의 근접 표현을 상황에 맞춰 교열했다. 점수 간 동일 행동도 의미가 바뀌지 않는 범위에서 문장을 다듬었다.
- 완성 응답에서 상투어가 겹치지 않도록 work d50 v01의 `좋아.`를 제거했다. 통합 테스트가 추가로 찾은 recover 3묶음의 `분명하게` 중복은 총괄이 do 문구를 같은 행동의 구체적 표현으로 바꿨고 원고에도 동기화했다.
- 총괄 작성 원고의 추상적인 `몫`·`분량`, 부자연스러운 결합, 낮은 점수의 불필요한 단정을 교차검수해 수정했다. organize의 요청 표본 28묶음은 공통 의도와 점수 방향을 확인했고 자연어 5건을 총괄이 반영했다.

## 검사와 한계

- 한국어 12개 최종 shard에서 2,400묶음 / 11,200표현 수량을 확인했다.
- 전체 정확 중복 0, 같은 점수·유형 또는 분야 셀의 같은 필드 유사도 0.72 이상 0, 확인한 금지어 0. 런타임 로더의 어휘·분야 검사는 총괄의 통합 검사 결과와 함께 확인한다.
- 검사 스크립트는 누락·정확 중복·근접 문장·금지어를 찾는 보조 수단이다. 의미 일치와 자연스러움을 자동으로 보장하지 않는다.
- 이번 기록은 AI 에이전트 집필과 교차검수 결과다. 독립적인 사람 원어민 편집자의 전수 검수나 실제 사용자 반응 검증은 수행하지 않았다.
- UI·색상·API 연결·실제 표시 조합 및 개발 환경 검증은 총괄의 통합 범위다. 이 노트만으로 런타임 배포나 제품 품질 검증 완료를 선언하지 않는다.

최종 런타임 통합·서버/개발 DB 검증 결과는 [기준 문서 4.7절](../DAILY-FORTUNE.md#47-검수-과정과-결과)을 따른다.
