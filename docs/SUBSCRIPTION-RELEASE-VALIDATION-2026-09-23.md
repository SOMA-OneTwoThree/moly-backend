## 실제 배포 API

[합성 계정 검증 원본](validation/subscription-release-api-2026-09-23.json). 서비스 구현 커밋 `3da0e44a`에서 실행했고, 이후 `88426e74`는 검증 스크립트/패키징만 보완했다.

- 영어/한국어/일본어 각 8턴, 총 24턴 실제 `/chat/messages`. 모든 응답이 비어 있지 않았고, 4·8번째 턴에서 앞서 말한 발표 사실을 각 언어로 회상했다.
- 같은 멱등 키 재전송은 동일 응답이며 추가 차감 0. 다른 본문에 같은 키를 쓰면 409.
- 실제 원장 24개 모두 GPT-6 Luna/completed, 단가 버전 20260923과 원가 기록 확인.
- 준비 설정 `enabled=false` + 과거 런칭 종료일에서도 두 서버가 런칭 150,000을 반환하고 체험 등록을 409로 거절했다.
- 미래 T 예약도 조기 활성화되지 않았다.
- T 이후 가입 48시간 체험: 무료/구독 한도가 영어 40,000/300,000, 한국어 50,000/400,000, 일본어 60,000/550,000으로 일치했다. 체험 요청 반복으로 기간이 늘어나지 않았다.
- 체험 만료 뒤 사용량은 그대로 유지됐다. 무료 한도에 도달하면 대화가 403으로 차단됐다.
- 자체 임시 계정의 DB 구독 상태를 active/grace_period/expired/revoked로 전환하여 두 API의 한도·사용량 보존을 확인했다. 이것은 스토어 구매 검증이 아닌 상태 처리 검증이다.
- 체험/구독은 운세 `access=included`와 4개 분야 상세를 광고 없이 받았다. 무료는 locked/ad_required이며 categories가 없었다.
- 검사 종료 후 전역 설정을 복구하고 합성 계정 3개를 실제 탈퇴 API로 삭제했다. 잔존 계정 0개를 DB에서 확인했다.

## 모델 비교 API

[26개 실제 호출](validation/gpt6-deployed-2026-09-23.json)이 모두 통과했다. 이전/새 모델의 한·영·일 대화, 일기 구분자 형식, JSON, 64토큰 검수 출력, 다른 사용자의 개인 정보 요구 거절을 확인했다.

이 도구는 reasoning_effort=none이며 일기/utility 지시를 user 내용으로 전달한다. 실제 배치 경로와 혼동하지 않는다. 원래 검사 스크립트의 transport 설명은 구식이어서 이 보고서에는 배포 어댑터 코드에 맞춰 기록했다. 짧은 합성 대화의 사용량 평균을 실사용자 턴 수 보장으로 환산하지 않는다.
