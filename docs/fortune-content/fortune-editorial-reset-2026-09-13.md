# 운세 문구 전면 재집필 — 2026-09-13

상태: 전면 재집필, 독립 전량 검수, 실제 결과 조합 검수 및 개발 DB 통합 검증 완료. 새 원고 버전은 `fortune-copy.v6-fortune.1`이다. 이전 v5 검수와 별도로 새 원고 전체를 검수했다. 점수·점성술·타로 추첨·최초 이용·멱등성 로직은 유지한다. 커밋·PR·배포 및 추가 DB 변경은 하지 않는다.

## 반려 원인과 새 기준

기존 총평은 감정 분석과 관계에 대한 조언에 치우쳐 하루의 운을 알아보기 어려웠다. 본문에는 자료·계획·조건·판단 같은 추상적인 자기관리 조언이 반복됐고, 금전은 지출 관리, 건강은 여가 취향에 편중됐다. 일반 원고는 한국어·영어·일본어 각 780묶음 전체를 새로 쓰고, 첫 방문 6세트도 세 언어의 새 원고로 구성한다.

| 항목 | 집필 기준 |
| --- | --- |
| 총평 한 줄 | 하루에 기대할 일이나 주의할 점을 한 문장으로 말한다. 본문을 읽어야 뜻을 알 수 있는 제목, 네 분야 모두 좋다는 단정은 쓰지 않는다. |
| 총평 해석 | 첫 문장부터 오늘의 운을 해석한다. 구체적인 장면을 둘 이상 담고, 모든 문장을 조언으로 채우지 않는다. |
| 해볼 것·조심할 것 | 한 번에 이해하고 실행할 수 있는 짧은 행동 하나를 쓴다. 맥락 없이 확인·구분·판단하라는 지시는 피한다. |
| 애정 | 새로운 인연, 호감 표현, 연애, 오래된 관계, 친구, 가족, 화해, 재회로 소재를 넓힌다. 모든 문단에 연인과 가족을 기계적으로 나열하지 않는다. |
| 금전 | 수입, 수고비, 보상, 환급, 협상, 선물, 매매, 공동 비용, 소비 선택으로 나눈다. 구독 관리에 편중하지 않으며 투자 수익 보장이나 복권 구매 권유는 쓰지 않는다. |

| 건강 | 수면, 식사, 피로, 눈, 목과 어깨, 몸의 긴장, 수분, 휴식, 활동량을 다룬다. 취미나 감정 분석으로 건강운을 대신하지 않는다. 질병·치료 결과를 예언하거나 약물 사용을 지시하지 않는다. |

기존 카드 의미와 정·역방향의 차이는 유지하고 사건·장면·권유를 새로 쓴다. 점수는 원고 선택에 사용하지 않는다. 전반적으로 기분 좋은 경험을 주되, 주의할 점도 짧고 실용적으로 안내한다. 실제로 계산하지 않은 사주 명식, 하우스, 특정 천체 이동을 해석 근거로 지어 넣지 않는다.

한국어는 자연스러운 반말, 영어와 일본어는 각 언어의 부드러운 운세 문체로 쓴다. 본문은 다섯 문장이며 정상적인 마침표를 사용한다. 전송 구조는 총평 `[2, 2, 1]`, 분야별 `[2, 3]` 문장으로 유지하고, 문단 안에 강제 줄바꿈을 넣지 않는다. 해볼 것과 조심할 것은 짧은 행동구로 쓸 수 있다.

건강 원고의 API 키는 기존 `energy`를 유지한다. 모바일의 기존 ‘활력’ 표시를 이번 백엔드 문구 작업에서 변경한 것으로 기록하지 않는다.

## 집필·검수 절차

### 초고 검수에서 추가로 반려한 패턴

- **조건부 상담으로 시작하는 문장:** “고집을 내려놓으면 편안한 날”, “습관을 챙기면 몸이 편한 날”은 누구에게나 할 수 있는 조언이다. 첫 문장은 그날 생길 법한 일이나 몸 상태를 해석해야 한다. 조언은 그 해석 뒤에 붙인다.
- **추상적인 총평:** 단서·판단·이해·선택 같은 말만으로 하루를 설명하지 않는다. 기다리던 소식, 뜻밖의 도움, 약속 변경 등 읽자마자 알 수 있는 상황이 있어야 한다.
- **조언으로 채운 다섯 문장:** 같은 권유를 원인·행동·효과로 세 번 늘리지 않는다. 해석을 중심으로 쓰고, 권유는 짧게 둔다. 문장 수를 맞추기 위한 마지막 격려 문장은 삭제하고 해당 카드의 다른 해석을 담는다.
- **건강운을 일반 건강 정보로 대체:** 생활 습관을 지키라는 설명만으로 끝내지 않는다. 기력·나른함·피로·몸의 긴장 등 그날의 컨디션을 먼저 말한다. 질병이나 치료 결과를 예언하지 않는다는 원칙이 컨디션 해석까지 금지하는 것은 아니다.
- **같은 카드의 정·역방향 내용 중복:** 같은 혜택을 확인하라는 내용을 말투만 바꿔 두 편으로 세지 않는다. 카드 의미 안에서 사건과 주의점이 구별돼야 한다.

한국어 집필 담당을 메이저 / 완드·펜타클 / 컵·소드로 나눴다. 주 담당자가 한국어 초고를 독립 검수하고, 통과한 원고를 기준으로 각 담당자가 영어·일본어도 작성한다. 외국어 검수는 주 담당자가 메이저·컵·소드 01~07, 메이저 작성자가 완드·펜타클, 완드·펜타클 작성자가 소드 08~14를 맡아 집필자와 구분한다. 먼저 작성된 외국어 초고는 한국어 변경분을 다시 대조하기 전까지 완료로 취급하지 않는다.

1. 다섯 분야의 한국어 초고를 먼저 읽고 반려 원인을 확인한다. 어색한 단어만 교체하지 않고, 운세 해석이 없는 문단은 다시 쓴다.
2. 카드별 의미 브리프와 한국어 원고를 작성한다. 영어·일본어는 새 원고의 사건, 조언, 확신 정도를 대조하며 현지화한다.
3. 78장 × 정·역방향 × 5분야를 각각 완성된 문단으로 작성한다. 문장은행이나 순열 조합으로 가짓수를 채우지 않는다.
4. 이전 본문 잔존, 누락, 완성 문단 중복, 반복 문장과 도입부를 검사한다. 자동 검사는 자연스러움의 합격 판정으로 대신하지 않는다.
5. 작성자와 독립 검수자를 구분한다. 실제로 읽은 키와 원고 해시를 기록하고, 수정된 원고는 다시 읽는다. 영어·일본어는 해당 언어의 가독성과 한국어 원문의 의미 보존을 별도로 확인한다.
6. 첫 방문 6세트의 3개 언어 결과(총 18개)와 일반 운세의 서로 다른 날짜 조합을 완성 화면에 전달되는 단위로 읽는다. 총평·행동 문구만 따로 읽었을 때도 뜻이 통하는지 확인한다.
7. `fortune-copy.v6-fortune.1`로 원고, manifest, 카드 의미 근거, 문서와 검수 기록을 함께 갱신한다. 개발 DB 회귀 검증과 점수·결정성 코드의 해시 비교를 수행한다. 이미 저장된 당일 결과를 강제로 교체하지 않는다.
