# 한국어 운세 쉬운 말 재작성 기준

2026-09-16 사용자 교정에 따른 새 원고다. 이전 `ko-actions.r2`의 35~80자, 이유·조건을 붙인 1~2문장, 짧은 행동 이름 금지 기준은 이번 원고에 적용하지 않는다. 예전 검수 통과 기록을 새 원고의 승인으로 쓰지 않는다.

## 사용자가 직접 제시한 말투

- “오늘은 행복한 하루가 될거야.”
- “실수하는 걸 조심해.” — 모든 문구를 실수 주제로 쓰라는 뜻이 아니라 쉽고 직접 말하라는 예시다.
- “잘 모르는 부분을 물어보기.”
- “실수 이후에 변명하기.”
- “경험자에게”처럼 일상 대화에 어울리지 않는 말, “지적 받자마자”처럼 불필요하게 상황을 좁히는 말은 쓰지 않는다.

## 실제 작성 규칙

1. 총평은 오늘의 운을 바로 말하는 짧은 한 문장이다. 본문을 읽거나 뜻을 풀어야 이해되는 요약은 반려한다.
2. 해볼 것은 평소 쓰는 말로 적은 행동 하나, 조심할 것은 피해야 할 행동 하나로 쓴다. 사용자의 `물어보기`, `변명하기`처럼 `~하기` 형태를 사용한다. 이유·교훈·가상의 사연을 붙여 길게 만들지 않는다. 행동의 뜻이 드러나는 데 필요한 말은 남긴다. 조심할 것에 `~하지 않기`를 써서 의미를 뒤집지 않는다.
3. 본문도 쉬운 말과 짧은 문장으로 쓴다. 필요한 운의 해석과 조언은 남기되 같은 말의 반복, 추상적인 설명, 작가가 꾸민 작은 사건은 덜어낸다. 쉬운 본문을 억지로 다시 쓰거나 모두 한 줄로 줄이는 것이 목표는 아니다.
4. `~겠어`, `흐름이야`, `반가운 변화`, `경험자`, `해결할 여지`, `기대할 만한`, `성과를 기대해볼 만한`, `수고를 줄일 수 있어` 같은 우회적인 설명으로 돌아가지 않는다. 정상적인 `~수 있어`까지 없애 모든 일을 확정하지는 않는다.
5. 카드의 실제 뜻과 정·역 차이는 유지한다. 작성자가 예전에 넣은 소재·상황·조건은 카드의 근거가 아니다. 그 조건을 유지하려고 문장을 다시 복잡하게 만들지 않는다. 점수에 맞춰 카드 해석을 바꾸지 않는다.
6. 총운은 2단락, 애정은 솔로·연애 중·이별 후의 3단락, 학업·직장은 2단락을 유지한다. 금전·건강은 기존과 같은 1~2단락이다. 본문 안에 분야 소제목을 붙이지 않는다. 단락 안에서는 마침표로 문장을 나눈다.
7. 금전은 돈이 들어오고 나가는 것과 재물운을 직접 말한다. 건강은 일상 건강과 부상 주의를 말한다. 전문적인 진단이나 특정 투자의 수익을 지어내지 않는다. 안전 설명이나 제작자 설명을 덧붙이지 않는다.
8. 이미 자연스럽고 뜻이 분명한 문장은 유지해도 된다. 동의어 치환, 무조건 전부 좋게 만들기, 카드마다 같은 문장을 채우기로 변경 건수를 늘리지 않는다.

## 후속 분량 지시

같은 작업 중 사용자가 “각 카테고리별 … 한 4~5줄을 원해”라고 지정했다. **분야 전체 본문**을 기준으로 하며 총평·해볼 것·조심할 것의 분량과 구분한다. 문장 4~5개를 화면 4~5줄이라고 설명하지 않는다.

본문은 우선 공백 포함 약 110~140자를 편집 목표로 삼는다. 현재 모바일 소스의 본문 15px, 좌우 여백 24px와 일반적인 휴대폰 폭을 참고한 근사치이며 기기에서 렌더링을 검증한 숫자는 아니다. 화면 폭·글꼴·접근성 글자 크기·단락 표시가 달라지면 줄 수도 달라진다. 모든 기기에서 정확히 4~5줄이라고 보장하거나 문구를 잘라 표시하지 않는다.

애정의 세 상황도 합계 기준이며 각 상황을 장문으로 늘리지 않는다. 학업·직장의 두 단락도 합계 기준이다. 너무 짧은 금전·건강은 카드가 말하는 운과 필요한 조언을 충분히 풀어 쓰되, 길이만 채우는 상식·가상의 사연·같은 말의 반복을 넣지 않는다. 110~140자는 검수 참고 범위로 사용하고 길이를 맞췄다는 이유만으로 합격시키지 않는다.

## 범위와 검수

한국어 5개 분야의 카드 정·역 780개 원고 전체, 그 안의 총평·해볼 것·조심할 것 468개 필드를 대상으로 한다. 문구는 담당 에이전트가 작성하고 root와 다른 담당자가 실제로 읽고 검수한다. 판정 기준은 독립적으로 읽었을 때 뜻이 바로 통하는지, 평소 쓰는 말인지, 사용자가 원하지 않은 상황이나 해석을 덧붙였는지, 카드 뜻과 분야를 지켰는지다. 문장 길이와 해시는 보조 검사일 뿐 합격의 근거를 대신하지 않는다.

이 폴더는 새 한국어 원고와 실제 검수 기록을 보관한다. 기존 배포 정본·현지화 검수 기록은 이전 버전의 기록으로 보존한다. 새 원고를 영어·일본어 검수까지 끝난 배포 자산처럼 표시하지 않는다. 초안 작성 단계에서는 PR·배포하지 않았으며, 이후 사용자의 “개발 서버에 다 반영해봐” 승인으로 한국어 서비스 자산 연결·dev PR·머지·배포·검증을 진행한다. DB·점수·추첨·멱등성·잠금 계약을 변경하지 않는다.
